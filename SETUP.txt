INSTALL THE PERSONAL FOOTER
Open https://thekaizenking.github.io/email-signatures/templates/personal.html in a browser, select its rendered footer, copy it and paste into the personal account’s signature editor. Copy the rendered footer, not the HTML source. The image contains Paul Armstrong and “Let’s keep in touch.” with the approved A monogram. It displays at 288 x 80 px and has no displayed email address.

APP SETTINGS
Hotmail/Outlook.com: Settings > Accounts > Signatures.
Gmail: Settings > See all settings > General > Signature.
Mailbird Classic: Menu > Settings > Identities > edit the correct sending identity.

Choose the correct personal sending account, save, select the appropriate new-message/reply defaults and inspect a new unsent message. Check the image size and appearance. Recipients may need to allow external images; this is controlled by their email app.
