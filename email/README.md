# Email assets

Use neutral folders rather than public mailbox addresses. The account-to-folder mapping is maintained privately and is not part of this repository.

## General

`general/signature.html` uses the approved versioned personal footer image in the same folder. The image and HTML do not display a mailbox address.

The `general/` folder is the only current email collection. Future collections can be added when required, using neutral names rather than mailbox addresses.

After the image URL is published and verified, install the signature in the appropriate mail identity and check an unsent message. Select the sending identity using the private account mapping. The old image host remains available for existing emails.
