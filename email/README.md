# Email assets

Use neutral folders rather than public mailbox addresses. The account-to-folder mapping is maintained privately and is not part of this repository.

## Personal

`personal/signature.html` uses the approved versioned personal footer image in the same folder. The image and HTML do not display a mailbox address.

## Business

`business/signature-template.html` references the approved image hosted by the website. There is no business signature image stored in this email section. The contact address is `{{EMAIL}}` in the public template; replace it privately before installation, including its mailto destination. Website and LinkedIn links remain live.

After image URLs are published and verified, install the personalised signature in the appropriate Outlook, Google or Mailbird identity and check an unsent message. Current sending identities are selected using the private account mapping.

The old image host remains available for existing emails. Current signatures use the new personal image path or the website-owned business image, as appropriate.
