Outlook.com: Settings → Account → Signatures. Gmail: Settings → See all settings → General → Signature. Mailbird Classic: Settings → Identities → edit the sending identity. Save and inspect an unsent message from each sender, including defaults for new messages and replies. Publish and verify the new image URLs before updating account settings. Do not send a test message unless separately requested.

The legacy host remains available for existing emails. New signature image releases receive new filenames; `signature.html` can point to the approved current version.
