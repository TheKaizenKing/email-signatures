# Email signatures

Approved artwork and reusable signature templates for Paul Armstrong and Gemba Group.

## Stable HTTPS images

| Asset | Permanent URL | Email display size |
| --- | --- | --- |
| Personal footer | https://thekaizenking.github.io/email-signatures/assets/v1/personal-footer.png | 288 × 80 px |
| Gemba identity | https://thekaizenking.github.io/email-signatures/assets/v1/business-identity.png | 288 × 76 px |
| Gemba logo tile | https://thekaizenking.github.io/email-signatures/assets/v1/gemba-signature-tile.png | 76 × 76 px |

These approved v1 files must remain available unchanged. Put future artwork under a new version directory so existing emails retain their original images. The repository and GitHub Pages site must remain public for recipients to load these URLs. Some email apps block external images until the recipient permits them.

## Templates

- [Paul’s personal signature](templates/personal.html) uses the approved image and no displayed email address.
- [Reusable Gemba business signature](templates/gemba-business.html) has placeholder name, role and email fields, live website and LinkedIn links, and the Action purple divider.
- [Installation notes](SETUP.txt).

The Gemba identity image contains Paul’s approved name and role. The generic business template uses the separate Gemba logo so other senders can edit their own details. Exact custom fonts in editable email text depend on the email app’s support; the approved identity artwork preserves its font shapes.

No Hotmail address, rejected designs, draft history or credentials are included.

[Paul’s Gemba signature](templates/business.html) uses the approved identity image, live contact links and the dark purple divider.

The approved transparent monogram is also available at https://thekaizenking.github.io/email-signatures/assets/v1/selected-a-monogram.png for an optional live-text personal footer.
